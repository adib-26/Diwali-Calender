# Optional Gemini assets for the five festival-day mini-games

The mini-games work now with lightweight emoji artwork. These sprite sheets
would make them feel more bespoke. Generate each as a PNG with a flat, solid
**chroma-key green background (#00FF00)** so its sprites can be separated with
a green-screen remover later. Do not use green, neon-lime, or green glow in
the assets themselves. Include no words, logos, watermark, shadows extending
into another cell, or decorative border. The listed dimensions are 4× the
on-screen size, keeping the game crisp on modern phone displays.

## Day 17 — Auspicious Finds

Save as `assets/images/easter-eggs/day-17-auspicious-finds.png`.

Create a **1536 × 512 px PNG**: three equal 512 × 512 px sprite cells, with
one object centred in each cell. The site will render each object at about
45–52 px.

> A polished 3D storybook game-asset set for Dhanteras: one small brass
> kalash, one shining brass bowl, and one gold coin, three clearly separated
> objects arranged in a horizontal row with generous space between each object.
> Warm saffron, ruby and gold palette, soft realistic highlights, friendly
> mobile mini-game style, solid chroma-key green background #00FF00, no green
> in the objects, no text, no watermark.
